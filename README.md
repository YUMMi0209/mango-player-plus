为芒果TV设计的视频辅助插件：快捷键打点、变速预览、截图录制，日志面板一键导出片段表。

## 0. 安装教程

Chrome 与 Edge 均为 Chromium 内核，安装方式相同：

1. 获取代码（任选其一）：
   - **下载压缩包（推荐）**：前往 <https://github.com/YUMMi0209/mango-player-plus/releases>，下载最新版的 `Mango_Player_Plus_v3.0.zip` 并解压；
   - 或 `git clone https://github.com/YUMMi0209/mango-player-plus.git` 克隆仓库。
2. 打开扩展管理页：
   - Chrome：地址栏输入 `chrome://extensions`
   - Edge：地址栏输入 `edge://extensions`
3. 开启页面右上角「开发者模式」。
4. 点击「加载已解压的扩展程序」（Edge 文案为「加载解压缩的扩展」），选择项目文件夹。
5. 打开芒果TV视频播放页即可使用；建议点击浏览器右上角插件图标，将其固定到工具栏。

> 也可通过 Edge 加载项商店直接安装：[芒着拉片 MG Player+](https://microsoftedge.microsoft.com/addons/detail/%E8%8A%92%E7%9D%80%E6%8B%89%E7%89%87-mg-player/alikcmgpkiphhhnddpelidmilahokmbm)

## 1. 快速上手

1. 在浏览器打开芒果TV视频播放页。
2. 直接用键盘打点：
   - `I` 打入点
   - `O` 打出点
   - `M` 打标记点
   - 用 `J` `K` `L` 变速预览
3. 点击浏览器右上角插件图标，打开日志面板。
4. 勾选需要的记录。
5. 点击「导出日志」得到 Excel 片段表。

## 2. 快捷键速查

| 快捷键 | 功能 |
| --- | --- |
| `J` | 减速播放（逐级减半，最低 0.25X） |
| `K` | 播放 / 暂停（恢复常速） |
| `L` | 加速播放（逐级翻倍，最高 16X） |
| `空格` | 恢复常速（不暂停） |
| `I` | 打入点：记录当前时刻为片段起点 |
| `O` | 打出点：与入点组成一条「片段」记录（自动计算时长） |
| `M` | 打标记点：记录当前时刻，可后续标记颜色 |
| `Shift + I / O / M` | 跳转到最近打下的入点 / 出点 / 标记点 |
| `,` / `.` | 逐帧后退 / 前进（按视频帧率 1 帧） |
| `PageUp` / `PageDown` | 后退 / 前进 1 秒（网页不随之翻页） |
| `S` | 截图：保存当前画面为 PNG（同时复制到剪贴板） |
| `C` | 截图并复制到剪贴板（不下载） |
| `R` | 开始 / 停止录制画面（含声音） |
| `Esc` | 取消进行中的批量截图 / 录制；网页全屏时退出全屏 |

> 在输入框或备注编辑中按键不会触发快捷键。

## 3. 视频控制栏

进入芒果TV视频页后，画面内会出现轻量控制栏。

### 顶部时间码

实时显示当前时间与状态徽章：

- `PLAY`
- `IN`
- `OUT`
- `MARK`
- `REC`

鼠标悬浮画面时，时间码自动平滑下移，避开新版播放器的顶部遮挡；移出画面后回到原位。

点击可复制当前时间码；打点后自动显示入点以来的计时。

全屏状态下：

- 时间码固定下移，位置不随鼠标移动
- 无操作 5 秒后自动隐藏，移动鼠标立即恢复

右键点击可弹出输入框，输入时间码直接跳转。

支持以下格式（**面板里右键双击时间码就地编辑时同样适用**，两者共用同一套解析逻辑）：

- `hh:mm:ss:ff`
- `mm:ss:ff`
- `mm:ss`
- `hhmmssff`
- `mmssff`
- `mmss`

操作方式：

- `Enter`：跳转
- `Esc`：关闭

### 鼠标悬停按钮

鼠标悬停画面时，左右两侧浮现圆形按钮：

- 左侧：截图
- 右侧：录制

录制中常驻显示，并带红色描边。

### 弹幕屏蔽

插件在适用站点启用期间自动隐藏视频弹幕，无需手动开启；离开站点或禁用插件后恢复显示。

## 4. 日志面板

点击浏览器右上角插件图标打开面板。

面板顶部「日志记录」下方显示当前视频标题，宽度随窗口自适应，拉宽窗口可显示更多文字。

点击标题即可就地改名：

- `Enter` 保存
- `Esc` 取消

修改后的标题会同步到：

- 「历史记录」列表
- 导出表格的标题列

弹窗 / 侧边栏模式会跟随当前标签页，切换网页后记录自动同步。

## 三种显示模式

点击右上角「模式」按钮可切换：

```text
弹窗 → 侧边栏 → 独立窗口
```

### 弹窗

紧凑窗口，页签切换：

```text
标记 | Mark / 片段 | Clip
```

竖线为主题强调色。

### 侧边栏

浏览器右侧侧边栏，两组记录上下堆叠，可折叠。

### 独立窗口

独立小窗，可脱离浏览器使用。

插件会记忆上次使用的模式：下次打开浏览器，点击右上角插件图标仍按该模式打开面板。

- 弹窗：直接弹出
- 侧边栏 / 独立窗口：会清空弹窗，以对应方式打开

## 记录操作

勾选记录用于导出或删除。

顶部计数标签或底部全选按钮可一键全选。

连续多选时高亮合并为一块圆角矩形：

- 仅首尾保留圆角
- 组内分隔线保留淡化

单条选中保持原样。

### 常用操作

- **点击时间码**：跳转到视频对应时刻
- **右键点击时间码**：复制紧凑时间码，例如：

```text
00391214
```

- **右键双击时间码**：就地编辑该时间码（`Enter` 保存 / `Esc` 取消，失焦即保存）；支持与控制栏右键输入相同的格式（含**不带分隔符**的 `hhmmssff` / `mmssff` / `mmss`）；片段记录可分别编辑入点、出点，时长自动重算
- **点击记录行其他区域**：为该条记录添加 / 编辑备注

### 批量截图 / 录制

在面板中勾选记录后（焦点保持在面板内）：

- 勾选**标记点**后按 `S`：弹出确认框，确认后按时间先后**依次自动截图**（批量截图只对标记点生效）
- 勾选**片段**后按 `R`：弹出确认框，确认后按时间先后**依次自动录制**（批量录制只对片段生效，录制入点到出点）
- 勾选类型与按键不符时不执行，提示需要勾选对应类型（标记点 / 片段）
- 任务进行中按 `Esc`：**取消批量任务**（焦点在面板或页面内均可）

执行期间画面会逐条跳转，页面右下角提示当前进度（如 `批量录制 2/5 · Esc 取消`），全部完成后提示成功 / 失败条数；文件名与手动截图 / 录制规则一致。

取消时正在录制的那一段**作废不保存**（避免留下半截文件），已完成的条目保留，提示为「批量录制已取消 — 已完成 N 条」。

批量任务逐条可靠执行：每段录制严格停在设定的出点，单条异常只记为该条失败而不中断整批；换集 / 面板刷新导致控制栏重建后任务仍继续。

### 标记点颜色

点击记录行右侧的色圆点设为对应颜色，再次点击取消。

颜色会写入导出的「颜色」列。

### 备注

带备注的记录始终显示备注行，与所在行的时间码左对齐，无需选中。

多行备注完整展示所有行，编辑与展示状态的换行、行距完全一致。

**点击记录行任意空白区域即可添加 / 编辑该条备注**（无备注时显示「添加备注…」入口；选中单条记录同样会显示入口）。

点击备注即可编辑：

- `Shift + Enter`：换行，输入框随内容自动增高
- `Enter`：保存并退出编辑（**不影响勾选状态**，方便接着批量截图 / 录制）
- `Esc`：取消

底部单行展示：

```text
已选 2条记录 | 3.5s
```

计时器统计已选中的入点到出点记录总时长。

未选中任何入出点记录时不显示。

## 5. 导出日志

勾选记录后点击「导出日志」，生成 `.xlsx` 表格。

包含两个工作表：

```text
标记 | Mark
片段 | Clip
```

### 标记 | Mark

导出字段：

- 序号
- 时间码
- 颜色
- 备注
- 链接
- 标题

### 片段 | Clip

导出字段：

- 序号
- 入点时间码
- 出点时间码
- 时长
- 备注
- 入点链接
- 标题

链接点击可在浏览器中直接打开并自动跳转到对应时刻。

---

## 导出文件命名

Excel 导出文件名按以下规则命名：

```text
标题_时间码_备注
```

说明：

- 标题取该条记录的标题（面板上重命名过的标题优先，否则网页标题）
- 时间码为紧凑格式 `HHMMSSFF`（如 `00115210`）
- 备注取自**同一条记录**（首条选中项），与时间码一一对应；无备注时为「标题_时间码」
- 不含保存时间戳与类型前缀；备注是否写入由设置中「文件名包含备注」控制

示例：

```text
乘风2026_00115210_高潮.xlsx
乘风2026_00115210.xlsx
```

## 6. 历史记录

点击面板右上角历史按钮，列出所有打过分集（视频）的历史记录——**跨网站全局汇总**（在任意网站打过的点都会出现在这里），按记录数排序。

勾选时可连续选择多项，菜单不会关闭。

每行显示：

- 节目标题
  - 与面板上修改过的标题同步
  - 鼠标悬浮时标题变为主题色
- 标记数量
- 片段数量
- 点击该行即可打开对应视频

记录之间以分割线分隔，多选高亮与日志列表一致（合并为圆角矩形）。

记录被删除后，历史列表实时同步移除（含跨网站全局索引）。

顶部提供：

- 「导入」（全选左侧）：选择日志 Excel 导入，或把 `.xlsx` 直接拖入插件窗口（支持多文件）
- 「全选」
- 「清除选中」

导入时与当前视频页匹配的记录合并进页面日志（按时间码去重），其他视频的记录进入导入明细并在历史记录中合并显示。

### 导入质检表

两个入口：**拖入 `.xlsx`**（或点历史栏「导入」按钮选文件）会带上自动识别结果；点历史栏的 **AI 导入**按钮（星形）则直接用 AI 转换。弹窗以 **AI 优先**：

**① 交给 AI 转换后粘贴（推荐，格式再杂也能用）**

1. 点「复制提示词」（也可点「查看提示词」展开后手动复制，按钮会切换成「隐藏提示词」）
2. 把提示词 + 质检表一起发给任意 AI 工具（表格可直接上传，或贴截图 / 文本）
3. 把 AI 输出的清单**整段粘贴**到输入框 → 显示「将导入粘贴内容：N 个标记点」→ 点「导入」（**粘贴内容优先**，此时下面的表格勾选自动置灰忽略）

- 表格有多个工作表时，弹窗会多一个「**让 AI 只整理工作表**」下拉（默认「全部工作表」），选中的名字会写进提示词，避免 AI 把上集 / 下集或汇总表混在一起
- 提示词里约定了输出格式：每行「时间码 + 项目说明」；**时间码统一写成规范格式**（`时:分:秒:帧` / `时:分:秒`，原表的中文冒号、分号、纯数字等不规范写法由 AI 转成英文冒号），备注按「**品牌 → 艺人 → 权益 → 时长**」拼接、缺的部分省略（如 `阿维塔 张泉灵 4s`、`趣多多 张彬彬 食用`）
- 粘贴内容兼容纯文本（自动忽略列表符号、序号、markdown 表格外框）与 JSON 数组；插件本身也直接兼容中文冒号 / 分号的时间码，表里原文粘贴进来同样能识别

**② 或勾选自动识别结果导入**（默认折叠、且默认不勾选）

- 点开折叠行后**勾选要导入的工作表 / 分集**（同一工作表里含「上集 / 下集」会拆成两项），每项显示标记点数与备注预览，折叠行上显示已选点数
- 时间码自动识别：`HHMMSSFF`、`MMSSFF`、`HHMMSS`、`MMSS`、带分隔符的 `hh:mm:ss:ff`（中英文冒号 / 分号都算）、多打/漏打一位的数字串
- 备注只写**该条对应的项目**：单元格里紧跟时间码的说明与【品牌】标记（`00295306趣多多空镜` → `趣多多空镜`、`【阿维塔】013218` → `阿维塔`），**不带**列分类（植入 / 空镜…）、分线等额外信息；单元格里只有时间码时（露出表这类）退化为品牌 / 秒数（`阿维塔 4s`）
- 同一时刻的重复记录自动合并备注，超出视频时长的行自动丢弃

两种方式都按**标记点**导入到**当前打开的视频**；**时间码读法自动判定**（6 位数字按视频时长区分 `HHMMSS` / `MMSSFF`，8 位按 `HHMMSSFF`、4 位按 `MMSS`），解析用的读法会显示在提示行里，无需手动选择。

「清除选中」可批量清除某个分集的全部记录，有二次确认。

## 7. 设置说明

| 设置项 | 说明 |
| --- | --- |
| 亮色模式 | 切换面板亮色 / 暗色主题 |
| 禁用弹幕 | 插件启用期间自动隐藏视频弹幕（默认开启，关闭后恢复显示） |
| 视频控制 | 关闭后画面内不再显示控制栏，快捷键仍然生效 |
| 打点自动截图 | 开启后 M 打点立即自动截图保存；I 打入点自动截图，O 打出点时保存最后一次 I 时刻的截图 |
| 时间码显示回避 | 悬浮画面时时间码自动下移避开顶部遮挡；关闭后时间码不再向下移动（默认：芒果TV开启、其他网站关闭） |
| 文件名包含备注 | 截图 / 录制 / 导出文件名在时间码后附加该时刻记录的备注（默认启用） |
| 应用于当前网页（实验） | 在其他非芒果TV网站启用打点与记录，需授予站点权限；授权失败或无法获取页面地址时面板会提示原因 |
| 网页全屏 | 视频铺满当前窗口（非浏览器全屏），按 ESC 退出 |
| 重载插件 | 重新加载整个插件：修改代码后一键生效，面板会随之关闭 |

### 导出文件命名

```text
标题_时间码_备注.png        （截图，含打点自动截图 / 标注截图）
标题_时间码_备注.webm / .mp4（录制，时间码为入点时间码）
标题_时间码_备注.xlsx       （日志导出）
```

> 文件名由「标题 + 时间码 + 备注」三部分组成（无备注时省略备注），不加保存时间、类型前缀等多余信息；标题优先取面板上重命名过的标题，否则取网页标题。时间码与备注取自同一时刻，保证两者一致，录制的时间码固定为**入点时间码**。

## 8. 常见问题

### 面板提示「当前页面无法访问视频」怎么办？

面板只能在芒果TV视频播放页，或已开启「应用于当前网页」的站点使用。

弹窗 / 侧边栏会自动跟随当前激活的标签页，切换到视频页后即可恢复。

独立窗口会跟随打开时记忆的来源视频标签页。

---

### 按 I / O / M 没有反应？

请先确认焦点不在输入框内。

另外，`J` / `K` / `L` 变速前需先播放视频。

---

### 录制的视频没有声音？

浏览器对录制声音有权限限制。

请确认：

- 视频已播放过，浏览器认为你有权播放
- 浏览器未开启「静音标签页」

部分加密内容可能被浏览器禁止采集声音。

---

### 换集后记录会丢失吗？

不会。

每条记录都挂在对应分集的 key 下，面板会自动切换显示当前分集的记录。

「历史记录」里可以随时跳回任意分集查看。

---

### 导出的 Excel 打不开？

导出的文件为标准 `.xlsx` 格式。

请使用以下工具打开：

- Excel
- WPS
- 腾讯文档

若提示损坏，请更新软件版本后重试。
