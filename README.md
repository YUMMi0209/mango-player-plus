# 芒着拉片 | MG Player+

芒着拉片（MG Player+）将剪辑软件的时间码和变速导航逻辑带入芒果TV，拉片时可用 J/K/L 快速浏览素材、标记关键帧、复制时间码、以 PNG 截图 / MP4 录制输出片段，并在记录面板中导出片段表。

## 使用方式

1. **安装扩展**：Chrome 打开 `chrome://extensions`，开启右上角「开发者模式」，点击「加载已解压的扩展程序」，选择本项目目录。
2. **打开视频**：访问芒果TV（https://www.mgtv.com）并打开任意免费视频，播放后控制栏自动出现在画面顶部。
3. **快速拉片**：按 `L` 加速 / `J` 减速 / `K` 暂停，用 `,` `.` 逐帧进退，`I` `O` `M` 标记出入点与关键帧。
4. **输出素材**：`S` 截图 PNG，`R` 录制 MP4 片段；时间码点击即可复制。
5. **记录汇总**：点击工具栏图标打开记录面板，勾选记录后可清除或导出 Excel 片段表。
6. **非芒果TV 网页**：设置菜单开启「应用于当前网页」并授权后，任意含 `<video>` 的网页均可使用。

## 导航

| 键 | 功能 |
|----|------|
| `J` | 减速（1X → 0.5X → 0.25X） |
| `L` | 加速（1X → 2X → 4X → 8X → 16X） |
| `K` / `Space` | 播放 / 暂停 / 恢复 1X 速度 |

> J/L 共享同一个速度值，按 L 加速后再按 J 从当前速度往下降。暂停或按空格后速度恢复为 1X。

## 快捷键

| 键 | 功能 |
|----|------|
| `J` | 减速（÷2） |
| `L` | 加速（×2） |
| `K` / `Space` | 播放 / 暂停 / 恢复 1X 速度 |
| `,` / `.` | 前一帧 / 后一帧 |
| `I` / `O` | 标记入点 / 标记出点|
| `M` | 标记点 |
| `Shift+I` / `Shift+O` | 跳转入点/出点 |
| `Shift+M` | 跳转标记点 |
| `S` | 截图 PNG |
| `R` | 录制开关（输出 MP4 / WebM） |

## 时间码

| 标签 | 颜色 | 含义 |
|------|------|------|
| PLAY | 橙 | 1X 播放 |
| STOP | 灰 | 暂停 |
| 0.5X / 2X / 4X ... | 橙 | 变速播放 |
| IN | 蓝 | 入点，实时计时 |
| OUT | 绿 | 出点，冻结时长 |
| MARK | 黄 | 标记点 |
| REC | 红 | 录制中 |

- 速度不为 1 时标签显示具体倍数（含 0.5X/0.25X）
- 点击时间码复制紧凑格式（`00115210`）
- IN/OUT/MARK 状态 2 秒后自动恢复

## 录制

按下 R 键从**当前位置**开始录制（自动播放，跳转锁定），再次按下结束（自动暂停），输出 MP4 片段（浏览器不支持 MP4 录制时自动回退 WebM）。若录制恰好在入点开始，播放到出点会自动停止；其余情况录制与入点/出点无关，也不会改动已打好的出入点。视频播完同样自动停止。截图与录制文件以 `MG_` 开头，末尾附带输出时间。

## 控制栏

控制栏在视频顶部显示，包含逐帧进退、时间码、截图和录制按钮。全屏时自动隐藏，鼠标移至顶边浮现。

## 记录面板

点击工具栏图标打开记录面板（弹窗 / 侧边栏分屏 / 独立窗口），记录标记点与入点到出点：

- 弹窗模式：左右页签切换两种记录；分屏模式：上下堆叠双列表；独立窗口模式：样式同分屏，以独立窗口常驻系统任务栏
- 头部**模式按钮**可随时在「弹窗 / 分屏 / 独立窗口」三种模式间切换
- 标记点与入点到出点均为单列竖向列表，仅保留下边框，便于逐行点选
- 记录按视频（项目 ID + 分期 ID）独立保存：切换同项目不同分集或不同视频时，面板自动切换对应记录，互不干扰
- 每条标记点时间码右侧提供红 / 橙 / 蓝 / 绿 / 灰五种颜色标记：默认无颜色且色点为空心，点击色点打色后对应色点变为实心（再次点击取消），打色 / 取消时 Toast 提示色名。选择颜色不影响时间码本身的标记黄
- 勾选记录后可「清除记录」或「导出 Excel」（.xlsx，含时间码、时长与定位链接）；删除记录前会弹出二次确认
- 导出表格的标记点带「颜色」字段（红 / 橙 / 蓝 / 绿 / 灰 或「无」）
- 芒果TV 记录的链接带 `#mpp=` 定位，点击跳转到对应时间点
- 面板头部**刷新按钮**：不关闭弹窗/侧边栏，仅重启页面端服务（重扫视频、重建控制栏、重载记录）——切换视频后控制栏未出现时点击即可恢复

## 设置

面板右上角齿轮按钮打开设置菜单：

- **插件开关**：关闭后整个扩展暂停（控制栏、打点、录制与面板记录均停用）
- **亮色模式**：切换浅色界面
- **应用于当前网页**（实验）：对非芒果TV 站点开启支持（首次需浏览器授权），开启后任意含 `<video>` 的网页均可用
- **清除所有记录**（设置菜单底部大按钮）：一键清除该站点所有网页 / 分集的标记点与入点到出点记录（需二次确认）

## 技术

- 默认仅对芒果TV 生效，可对任意网页开启；Shadow DOM 样式隔离
- 帧率自动检测（25/30/50/60fps）
- Canvas + MediaRecorder 截图 / 录制（MP4，WebM 后备）
