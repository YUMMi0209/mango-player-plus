# 芒着拉片 | MG Player+

芒着拉片（MG Player+）将剪辑软件的时间码和变速导航逻辑带入芒果TV，拉片时可用 J/K/L 快速浏览素材、标记关键帧、复制时间码、以 PNG 截图 / MP4 录制输出片段，并在日志面板中导出片段表。

## 使用方式

1. **安装扩展**：Chrome 打开 `chrome://extensions`，开启右上角「开发者模式」，点击「加载已解压的扩展程序」，选择本项目目录。
2. **打开视频**：访问芒果TV（https://www.mgtv.com）并打开任意免费视频，播放后控制栏自动出现在画面顶部。
3. **快速拉片**：按 `L` 加速 / `J` 减速 / `K` 暂停，用 `,` `.` 逐帧进退，`I` `O` `M` 标记入点、出点与关键帧。
4. **输出素材**：`S` 截图 PNG，`R` 录制 MP4 片段；时间码点击即可复制。
5. **记录汇总**：点击工具栏图标打开日志面板，勾选记录后可清除或导出 Excel 片段表；选中单条记录可为其添加备注。
6. **非芒果TV 网页**：设置菜单开启「应用于当前网页」并授权后，任意含 `<video>` 的网页均可使用；授权失败时面板会提示原因，请在浏览器弹出的授权窗口中点击允许。

## 导航

| 键 | 功能 |
|----|------|
| `J` | 减速（1X → 0.5X → 0.25X） |
| `L` | 加速（1X → 2X → 4X → 8X → 16X） |
| `K` / `Space` | 播放 / 暂停 / 恢复 1X 速度 |

> J/L 共享同一个速度值，按 L 加速后再按 J 从当前速度往下降。暂停或按空格后速度恢复为 1X。

## 快捷键

| 键 | 功能 |
|----|------|
| `J` | 减速（÷2） |
| `L` | 加速（×2） |
| `K` / `Space` | 播放 / 暂停 / 恢复 1X 速度 |
| `,` / `.` | 前一帧 / 后一帧 |
| `I` / `O` | 标记入点 / 标记出点|
| `M` | 标记点 |
| `Shift+I` / `Shift+O` | 跳转入点/出点 |
| `Shift+M` | 跳转标记点 |
| `S` | 截图 PNG |
| `R` | 录制开关（输出 MP4 / WebM） |

## 时间码

| 标签 | 颜色 | 含义 |
|------|------|------|
| PLAY | 橙 | 1X 播放 |
| STOP | 灰 | 暂停 |
| 0.5X / 2X / 4X ... | 橙 | 变速播放 |
| IN | 蓝 | 入点，实时计时 |
| OUT | 绿 | 出点，冻结时长 |
| MARK | 黄 | 标记点 |
| REC | 红 | 录制中 |

- 速度不为 1 时标签显示具体倍数（含 0.5X/0.25X）
- 点击时间码复制紧凑格式（`00115210`）
- IN/OUT/MARK 状态 2 秒后自动恢复

## 录制

按下 R 键从**当前位置**开始录制（自动播放，跳转锁定），再次按下结束（自动暂停），输出 MP4 片段（浏览器不支持 MP4 录制时自动回退 WebM）。若录制恰好在入点开始，播放到出点会自动停止；其余情况录制与入点/出点无关，也不会改动已打好的出入点。视频播完同样自动停止。截图与录制文件以 `MG_` 开头，末尾附带输出时间。

## 控制栏

控制栏顶部居中显示时间码（点击复制）；鼠标靠近画面时，截图与录制按钮浮现于视频垂直中间左、右两侧（录制中常驻）。录制中按钮呈红色高亮并带红色描边。逐帧进退使用键盘 `,` `.` 操作。

## 日志面板

点击工具栏图标打开日志面板（弹窗 / 侧边栏 / 独立窗口），记录标记点与入点到出点。面板为**复古磁带机**风格：CRT 扫描线背景、LED 计数器式时间码（发光数字）、卡带机按键式页签、磁带条纹边饰。

- 弹窗模式：左右等宽页签切换两种记录；侧边栏模式：上下堆叠双列表；独立窗口模式：样式同侧边栏，以独立窗口常驻系统任务栏，并始终跟随来源视频标签页刷新
- **跨网页同步**：弹窗 / 侧边栏模式跟随当前窗口的激活标签页，切换到其他视频网页时记录自动同步；独立窗口跟随记忆的来源标签页
- 头部**模式按钮**可随时在「弹窗 / 侧边栏 / 独立窗口」三种模式间切换（各模式选项带图标）
- 面板标题下以一行小字显示当前视频标题（直接读取网页 `<title>` 字段完整文本，宽度随窗口自适应，超长截断）
- 标记点与入点到出点均为单列竖向列表，仅保留下边框，便于逐行点选；时间码等关键信息不会被截断；连续多选时高亮合并为一块圆角矩形（组内分隔线保留淡化），单条选中保持原样
- 记录按视频（项目 ID + 分期 ID）独立保存：切换同项目不同分集或不同视频时，面板自动切换对应记录，互不干扰
- 每条标记点时间码右侧提供红 / 橙 / 蓝 / 绿 / 灰五种颜色标记：默认无颜色且色点为空心，点击色点打色后对应色点变为实心（再次点击取消），打色 / 取消时 Toast 提示色名。选择颜色不影响时间码本身的标记黄
- **打点备注**：带备注的记录始终在时间码下方展示备注行（与所在行的时间码左对齐，无需选中）；只选中一条记录时，无备注也显示「添加备注…」编辑入口。点击备注即可编辑并换行展开完整内容；Enter 保存、Shift+Enter 换行、Esc 取消。备注随记录保存，导出时写入「备注」字段（位于链接之前），视频标题写入「标题」字段（位于链接之后）
- 勾选记录后可「清除记录」或「导出 Excel」（.xlsx，含时间码、时长、备注、定位链接与标题）；删除记录前会弹出二次确认
- 底部单行展示「已选 x条记录 | xxs」：计时器统计**已选中**的入点到出点记录总时长，未选中任何入出点记录时不显示，竖线使用主题橙色
- **历史按钮**（设置右侧的时钟图标）：列出所有有标记记录的视频标题，支持跳转打开、连续勾选多项（菜单不关闭）并批量清除对应视频的全部记录

## 设置

面板右上角齿轮按钮打开设置菜单（从上到下）：

- **亮色模式**：切换浅色界面
- **日志记录**开关：控制打点（标记点 / 入点到出点）是否写入日志，关闭后面板提示不可用
- **视频控制栏**开关：控制视频画面内控制栏与按钮的显示，与日志记录互不影响
- **文件名包含标题**开关：开启后，截图 / 录制文件名开头附加网页标题（如 `MG_乘风2026第1期_…`，非法字符自动替换）；设置即时推送到所有打开的网页
- **文件名包含备注**开关：开启后，在带备注的标记点 / 入点 / 出点处截图或开始 / 结束录制时，输出文件名附带该备注（非法字符自动替换）
- **应用于当前网页**（实验）：对非芒果TV 站点开启支持（首次需浏览器授权），开启后任意含 `<video>` 的网页均可用；授权失败或无法获取页面地址时面板会提示原因
- **教程帮助**按钮：新标签页打开完整使用教程
- **重新加载**按钮：重新加载整个插件，修改代码后一键生效（面板随之关闭）

## 技术

- 默认仅对芒果TV 生效，可对任意网页开启；Shadow DOM 样式隔离
- 帧率自动检测（25/30/50/60fps）
- Canvas + MediaRecorder 截图 / 录制（MP4，WebM 后备）
