使用教程 · v5.0

边看边记，看完就能交表

芒着拉片是为审片、拉片设计的浏览器插件：在芒果TV（以及百度网盘、你授权的其他网站）上用键盘打点、变速、截图、录制，最后一键导出 Excel 片段表。下面按你手头的工作来讲，挑一个开始。

点工具栏的插件图标打开日志面板；右上角「模式」可切换弹窗 / 侧边栏 / 独立窗口，长时间审片推荐侧边栏。其他网站需在设置里打开「应用于当前网页」。

场景 1

审片打点，交一份片段表

你在审一集节目，需要把有问题的镜头和可用的片段记下来，最后交一份带时间码的 Excel。

  1. 用键盘控制播放K 播放 / 暂停，J L 逐级减速 / 加速（0.25X～16X），空格 回到常速；, . 逐帧，↑ ↓ 或 PageUp PageDown 前后 1 秒。中文输入法下的全角 ， 。 也有效。
  2. 边看边打点I 打入点、O 打出点，两者组成一条片段（自动算时长）；M 打一个标记点。Shift+I / O / M 跳回最近打下的点。画面顶部时间码会显示 IN / OUT / MARK 状态。
  3. 打开面板整理点工具栏图标。列表里时间码按类型着色：入点、出点、标记点。
    • 写备注：点记录行的空白处直接输入，Enter 保存，Shift+Enter 换行，Esc 取消。
    • 标颜色：标记点右侧的小圆点，点一下设色，再点取消。
    • 跳转：左键点时间码跳到那一刻；右键单击复制紧凑时间码（如 00391214）。
  4. 时间码打偏了？两种改法
    • 对着画面校准：把画面停在正确的那一帧，鼠标移到要改的时间码上，右侧出现 ↻ 小按钮，点一下就换成当前播放的时间码。标记点、片段的入点和出点都可以这样改；片段改完会重算时长，入点不能晚于出点。
    • 手动输入：右键双击时间码就地编辑，Enter 保存、Esc 取消。
  5. 勾选并导出勾选要交的记录（Ctrl+A 全选 / 取消），底部显示已选条数和片段总时长。点「导出日志」，得到含「标记 | Mark」「片段 | Clip」两张表的 .xlsx。
找记录更快：在面板里按 / 打开备注搜索，命中的词会高亮；输入框右侧的彩色圆点按颜色筛选标记点。搜索时「全选」只选中搜索结果，适合「搜某个品牌 → 全选 → 批量截图」。

导出的表格长什么样

  • 标记表：序号、时间码、颜色、备注、链接、标题；片段表：序号、入点、出点、时长、备注、入点链接、标题。
  • 链接带定位，点开浏览器会直接跳到那一刻；表格也能再拖回插件导入。
  • 所有单元格都是文本格式，011218 这类数字串不会丢前导零。
  • 文件名：标题_日志记录_导出时间.xlsx，标题优先用你在面板顶部改过的名字（点标题即可改）。
场景 2

截图给后期，把问题圈出来

你发现一处穿帮、字幕错误或调色问题，需要截一张图、圈出位置、写上说明，发到群里或贴进文档。

  1. 直接截图S 下载 PNG 并复制到剪贴板；C 只复制不下载，适合马上粘贴到聊天窗口。截完会暂停在这一帧，方便你确认。
  2. 需要标注时按 Shift+S画面冻结在当前帧并打开标注窗口，期间视频保持暂停，关闭后恢复原来的播放状态。
    • 画：拖拽画矩形 / 椭圆 / 自由线条，B 在三种工具间切换。
    • 写：在画面上点一下加文字，Enter 确认；贴边点击时文字会自动收进画面内。
    • 调：底部工具条选颜色、粗细、字号，可开「嵌入时间码」把时间码写进图片右上角。
    • 改：Z 撤销；点选某条标注后按 Backspace 删除。
  3. 保存或复制右上角「保存」（Enter）导出 PNG，「复制」（C）放进剪贴板，「取消」（Esc）放弃。
时间码可信：插件取的是「此刻真正显示在屏幕上的那一帧」，并自动修正片源首帧偏移。所以控制栏时间码、图里嵌入的时间码、文件名里的时间码是同一帧。截图文件名为 标题_时间码_备注.png（无备注时省略）。
场景 3

把一段画面录下来发给同事

文字说不清楚，你想把某个片段原样录下来，或者把一批片段一次性全部录好。

  1. 录一段按 R 开始，再按 R 停止（含声音）。录制中画面右侧的录制按钮变红并常驻，画面带红框。停止后自动下载 MP4，并暂停在最后一帧。
  2. 从入点录到出点先打好入点、出点，在入点处开始录制，到出点会自动停止。
  3. 批量录制在面板里勾选片段，按 R，确认标题后插件逐条跳转、逐条录制。正在处理的那条会高亮并自动滚动到可见处；Esc 取消（当前这段作废，已完成的保留）。

画质与兼容性

  • 默认 MP4 · H.264 Baseline + AAC，兼容性最好；分辨率和帧率跟随源视频。
  • 想要更好的画质与压缩效率，打开设置里的「高级录制编码/HiP」（实验），改用 High Profile。
  • 编码器没有输出时自动降级重录这一段：开着 HiP 时先自动关闭 HiP（会记住）改用 Baseline；Baseline 仍不行，这一段改用 WebM / VP9（不记忆，下次仍先用 MP4）。没有 AAC 编码器时自动改录无声，都会提示。
  • 要切到别的窗口继续录？打开「画中画保持录制」，切后台时视频进画中画继续渲染。
录制文件名为 标题_入点时间码_备注.mp4。批量截图同理：勾选标记点按 S。
场景 4

看 Log 素材套 709 的效果

你在看相机原始的 S-Log3 / C-Log3 素材，画面发灰，想快速判断套上官方 709 LUT 之后是什么样。

  1. 按 Q 循环REC.709（原始画面）→ SLog3 → CLog3 → 回到 REC.709。切到 LUT 档会自动进入网页全屏。
  2. 在网页全屏里审看底部浮动控制条：
    • 左侧橙色按钮播放 / 暂停，两侧显示当前时间与总时长。
    • 鼠标悬停进度条会显示该位置的时间，按下即定位、拖动跟随；在控制条上滚动滚轮前后跳 5 秒。
    • 右侧的 LUT 标签显示当前档位，点它等同按 Q；最右侧按钮退出全屏。
    • 2.5 秒不动鼠标，控制条和光标自动隐藏；暂停时保持显示。
  3. 退出Esc 或 P 退出网页全屏，LUT 会一起关闭。只想全屏看原片，直接按 P。
LUT 只影响你看到的画面：截图和录制仍是原始素材，方便在剪辑软件里另行调色。两条曲线分别是 Sony SLog3/SGamut3.Cine → LC-709 TypeA 与 Canon Cinema Gamut / CLog3 → Canon 709，需要浏览器支持 WebGL2。
场景 5

拿到片段表，逐条核对

客户或编导给了你一份片段表 / 记录表，你需要按表里的时间码一条条看过去，并截图留证。

  1. 导入表格把 .xlsx 拖进面板，或在「历史记录」里点「导入」。弹窗分三步：
    • 选择文件：可一次拖多个；一个时间码都没识别到时会停在这一步提示原因。
    • 选择工作表：只有一张表时自动跳过；↑ ↓ 选择，Enter 下一步。
    • 确认导入：清单里看到的就是将导入的内容，可直接改时间码和备注、删行或加行，再点「导入 N 条」。
  2. 逐条跳转核对在面板里点时间码跳过去看；不准的地方，停在正确的帧，用时间码右侧的 ↻ 按钮改成当前时间码。
  3. 批量截图留证勾选标记点（可先搜索品牌名再全选），按 S，确认标题后自动逐条截图。

表格里的时间码怎么写都行

支持 00:01:12:18、01:12:18、01:12、00011218、011218、0112，中英文冒号、分号、有无分隔符都可以；导入后统一显示为 HH:MM:SS:FF。011218 这类 6 位数字两种读法都成立时，会让你选一次「分:秒:帧」还是「时:分:秒」（默认前者）。

没有现成的表？导入弹窗左下角「下载空表」：标记表填「时间码 / 备注」，片段表填「入点 / 出点 / 备注」，只填时间码也能导入到当前视频。
场景 6

直播监看，按系统时间记录

你在盯一场直播，需要按真实时刻记录问题，方便和导播、技术对表。

  1. 打开直播模式直播页默认开启；其他页面在设置里打开（刷新后回到关闭）。顶部时间码变为系统时间 HHMMSSFF（按 25fps 折算帧号），状态标签显示 LIVE。
  2. 照常打点、截图、录制记录、截图和录制的时间码与文件名都使用系统时间。
  3. 回看芒果TV 直播页可用 ← → 回退 / 前进 30 秒。
直播模式下时间码不对应视频位置，所以按时间码跳转的功能都会停用（输入跳转、点记录跳转、链接定位），「时间码显示回避」也会关闭。
日常

管理多个视频的记录

一周审了十几集，你想回到之前的某一集，或者一次导出好几集的日志。

  • 历史记录（面板右上角时钟图标）汇总所有打过点的视频，跨网站。右上角可按添加时间、修改时间或名称排序，并切换升降序；点某一行打开该视频。
  • 批量导出：勾选多个视频点「批量导出」，每个视频一份日志表，打包成 zip；只选一个时直接给 .xlsx。
  • 删除：勾选后点垃圾桶图标，重启浏览器也不会再出现。
  • 换集不会丢：每条记录挂在对应分集下，面板自动切换显示当前分集的记录。百度网盘按链接里的媒体地址区分视频，不受改名影响。

排查

常见问题

没有匹配的问题
面板提示「当前页面无法访问视频」
面板只在芒果TV、百度网盘或已开启「应用于当前网页」的站点可用。确认当前是视频播放页、插件已启用；其他网站请在设置里打开「应用于当前网页」并在浏览器弹窗中点「允许」。弹窗 / 侧边栏会跟随当前标签页，切回视频页即可恢复。
按 I / O / M 没有反应
依次检查：焦点是否在输入框里；当前网站是否适用；按 O 之前是否已打过入点。J L 变速需要视频先播放。
Mac 上按 , . 没反应
中文输入法会把这两个键发成全角「，」「。」，插件同时按全角字符与物理键位识别。若仍无反应，确认焦点不在输入框、当前页面适用本插件。
百度网盘换了视频，记录还是上一个视频的
插件按链接里「s/ 与 &fpath 之间的媒体地址」区分视频，切换视频时会自动重载对应记录。如果没有切换，刷新一下面板。
芒果TV 自带的进度条 / 控制栏不见了
「禁用弹幕」只隐藏弹幕层。若整条控制栏消失，先关掉「禁用弹幕」确认是否为样式冲突，再反馈给作者。
录制的视频没有声音
按顺序排查：视频是否播放过、标签页是否被静音、内容是否允许采集声音。本机没有 AAC 编码器时插件会自动改录无声并提示。
录制帧率偏低、画面发顿
插件每个源帧只绘制一次，开销已经很低。若仍掉帧，多半是编码能力吃紧：关掉其他占 CPU 的程序，或先用较低清晰度播放再录。核显硬编不稳定时，把 Edge 的图形首选项设为「高性能（独显）」并完全重启浏览器。控制台 [MGP-REC] 日志里的 draws / encoderSlow 能看出瓶颈。
录出来是 .webm 而不是 .mp4
Baseline 档位也编不出数据时，这一段会自动改用 WebM / VP9 重录。这只针对当前这一段，下次录制仍会先用 MP4。若开着「高级录制编码/HiP」，插件会先自动关闭它、用 Baseline 重录，最后才改用 WebM。
LUT 没有效果
LUT 只在网页全屏中生效，且需要 WebGL2（Chrome / Edge 均支持）。不支持时会明确提示。截图与录制始终是原始画面，这是有意设计。
导出的 Excel 打不开 / 导入时识别不出时间码
导出的是标准 .xlsx，Excel、WPS、腾讯文档都能打开，提示损坏请更新软件。识别不出时间码时，确认时间码与说明在同一行（或同一列）。
换集后记录会丢吗
不会。每条记录都挂在对应分集下，面板会自动切换；「历史记录」里可以随时跳回任意分集。
