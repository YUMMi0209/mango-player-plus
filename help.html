芒着拉片｜MG Player+ 使用教程 · v3.3

为芒果TV设计的视频辅助插件：快捷键打点、变速预览、截图录制，日志面板一键导出片段表。

1安装与启用

  1. 获取代码（任选其一）：
    • 下载压缩包（推荐）：前往 https://github.com/YUMMi0209/mango-player-plus/releases 下载最新版压缩包并解压；
    • 或 git clone https://github.com/YUMMi0209/mango-player-plus.git 克隆仓库。
  2. 打开扩展管理页：Chrome 地址栏输入 chrome://extensions；Edge 输入 edge://extensions。
  3. 开启页面右上角的开发者模式。
  4. 点击「加载已解压的扩展程序」（Edge 文案为「加载解压缩的扩展」），选择项目文件夹。
  5. 打开芒果TV视频播放页即可使用；建议点击浏览器右上角插件图标，把它固定到工具栏。

也可通过 Edge 加载项商店直接安装。

可用的网站

网站说明
芒果TV默认白名单站点（www.mgtv.com / *.mgtv.com），打开播放页即可用，无需任何授权
百度网盘默认白名单站点（pan.baidu.com），同样开箱可用

「应用于当前网页」授权失败时会在网页上提示原因：拿不到页面地址会提示「无法获取当前网页地址，请刷新页面后重试」，没点允许会提示「未获得网页授权，请在浏览器弹窗中点击允许」。关掉开关会同时回收该域名的授权。

3视频控制栏

进入适用网站的视频页后，画面顶部会出现轻量控制栏（可在设置里用「视频控制」开关关闭）。

顶部时间码

时间码以实际渲染帧为基准，掉帧时与画面内嵌时间码仍然一致，格式为 时:分:秒:帧。左侧徽章显示当前状态：

PLAYSTOPINOUTMARKREC2X
  • 播放显示 PLAY，暂停显示 STOP，变速时显示倍速（如 2X）；
  • 打入点后徽章变为 IN，时间码切换为距入点的计时；打出点变 OUT；打标记变 MARK（标记点已设颜色时徽章同步该颜色）；录制中变 REC；
  • 单击时间码：复制当前时间码，不带分隔符，如 00391214；
  • 双击时间码：进入 / 退出网页全屏；
  • 右键时间码：弹出输入框，输入时间码直接跳转，Enter 跳转、Esc 关闭，点输入框外也会关闭；识别失败提示「无法识别的时间码」。

右键输入框与面板里「右键双击时间码」就地编辑共用同一套解析，支持六种写法：

格式示例说明
hh:mm:ss:ff00:01:12:18末段为帧号，必须小于当前帧率
mm:ss:ff01:12:18同上
mm:ss01:12秒必须小于 60
hhmmssff00011218无分隔的 8 位
mmssff011218无分隔的 6 位（分:秒:帧）
mmss0112无分隔的 4 位

时间码显示回避

鼠标悬浮画面时，时间码会自动平滑下移（约视频宽度的 2.5%），避开新版播放器的顶部遮挡；移出画面回到原位。

  • 可在设置里用「时间码显示回避」关闭；未手动设置过时按站点默认：芒果TV 开启、其他站点关闭。
  • 浏览器全屏时时间码固定下移（幅度更小、不做移动动画），并且无操作 5 秒自动隐藏，移动鼠标立即恢复。
  • 网页全屏时时间码位置固定下移，不受该开关影响。

画面两侧按钮

鼠标移到画面垂直中部的左右两侧（距边缘 70px 内）时，浮现两个圆形按钮：左侧截图（截图 (S)）、右侧录制（录制 (R)）。录制中两个按钮常驻显示，画面四周出现红色描边并呼吸闪烁。

直播回退

芒果TV直播页会保留 600 秒本地回退缓存，并禁用「落后直播边缘自动拉回」。用 ← / → 回退 / 前进 30 秒，画面下方提示「回退 30s ( 时间码 )」；已经贴到最新画面时提示「已到最新画面」。切换清晰度导致缓存重建时会提示「回退缓存已重建，可重新回退」。

弹幕屏蔽

插件在适用站点启用期间自动隐藏视频弹幕（按 danmu / danmaku 类名匹配的容器），无需手动操作；关闭设置里的「禁用弹幕」或禁用插件后恢复显示。

网页全屏

视频铺满当前窗口（不是浏览器全屏），不改变播放状态。进入方式：设置菜单里的「网页全屏」按钮，或双击控制栏时间码；退出方式：按 Esc，或再双击一次时间码。

  • 全屏期间页面其它元素（播放器 UI、标题悬浮层、导航等）自动隐藏，后插入的元素也会被隐藏；
  • 底部出现悬浮进度条：拖动即可实时跳转（气泡显示时间码）；按住不动 1 秒进入微调模式，进度条拉长到左右两端、范围收窄为目标位置 ±30 秒，便于精细定位；
  • 全屏期间双击画面会被插件拦截，避免误退出或切到浏览器全屏。

4截图、标注与录制

截图

快捷键行为提示
S保存 PNG 并复制到剪贴板成功「截图保存 · 已复制」，复制失败「截图保存（复制失败）」
C只复制到剪贴板，不下载「已复制截图」/「复制失败，请检查浏览器剪贴板权限」
Shift+S打开标注窗口（见下）录制中提示「录制中无法标注截图」

截图按视频原始分辨率保存；受版权保护、画布无法读取的内容会提示「截图失败: 内容保护」。

标注截图（Shift+S）

进入标注会先暂停视频，保证标注画面就是截图画面。窗口标题为「标注截图」，顶部提示「拖拽画框 · 点击加字 · Ctrl+C 复制 · Ctrl+Z 撤销」。

  • 画框：在画面上拖拽即可画一个白边 + 主题色的矩形框；
  • 加字：在画面上点击一下，就地弹出输入框输入文字，Enter 确认、Esc 取消、点别处也会确认；文字为白边 + 主题色粗体；
  • 撤销：Z 或 Ctrl+Z 撤销上一条标注；
  • 复制：C 或 Ctrl+C 把带标注的图复制到剪贴板（保存时不会自动复制）；
  • 保存 / 取消：Enter 保存（下载 PNG）、Esc 取消，也可点右上角「保存 (Enter)」「取消 (Esc)」，点击窗口外的空白区域同样取消；
  • 嵌入时间码：右上角开关，打开后在截图右上角叠加当前画面时间码；设置会被记住（默认关闭），编辑期间切换即时生效；
  • 窗口主题跟随设置里的亮 / 暗色模式；文件命名与直接截图完全一致。

打点自动截图（设置开关）

  • 开启后按 M 打标记点立即截图保存；
  • 按 I 打入点时暂存当前画面，按 O 打出点时保存最后一次 I 时刻的截图（时间码与备注都取入点时刻，保证文件名两者一致）；
  • 未手动设置过时按站点默认：百度网盘开启、其他站点关闭。

录制

按 R 开始，再按 R 停止。开始时的提示为「录制开始」；如果当前播放位置正好在入点且已有出点，会提示「从入点录制 → 到出点自动停止」——这一段会自己录到出点停止。视频播放结束、画面长时间无变化（约 8 秒冻结）、编码器异常时，录制都会自动停止并提示原因。

录制编码与分辨率

在设置「录制编码」里选，四档，默认 H.264：

档位容器分辨率规则
H.264MP4跟随视频本身分辨率（不缩放、不放大）
低分辨率 H.264MP4限制在 1280×720 以内（源更小则保持源尺寸），适合设备吃力时
VP8WebM跟随视频本身分辨率，实时性最好
VP9WebM跟随视频本身分辨率，压缩率更好但更吃 CPU
  • 采集帧率跟随源帧率，归一化到最接近的标准档（25 / 30 / 50 / 60fps），输出文件帧率与源一致；
  • 编码全部由 CPU 完成。编码确实跟不上时插件会自动降低帧率（60 → 50 → 30 → 25）并提示「设备编码能力不足，录制帧率已降为 N fps」；
  • 降级只降帧率、不中途改分辨率（中途改分辨率会让 MP4/H.264 出现花屏）。想要更低分辨率，请先切到「低分辨率 H.264」再重新录制。
  • H.264 档录制结束后会自动把视频重封装成经典 MP4（ftyp | mdat | moov，无 moof），方便剪辑软件读取；重封装失败会自动回退保存原始文件；
  • 所选编码浏览器不支持时，会按候选列表自动回退到可用的编码，文件扩展名随实际录出来的格式（.mp4 / .webm）；

录制色彩范围

浏览器从画布录出来的是全范围（0-255）画面，而多数播放器 / 剪辑软件默认按 limited（16-235）解释，会把画面再拉伸一次，黑位被压掉、看起来「颜色偏深」。插件的做法是从源头对齐：

  • 录制转绘时把画面压缩到 limited（对比度 85.88%，255→219）；
  • 容器标签一并改成 limited：WebM 改 Colour/Range（2→1），MP4 在重封装时改 SPS VUI 与 colr(nclx) 两处；
  • 截图（S 键 PNG）不做这个处理，仍是标准 sRGB，在浏览器里看就是原色；
  • VP9 档不做该修正：VP9 的范围写在码流内部，容器标签改不动，只改标签会造成画面与标签错配，因此 VP9 保持原样。

录制文件命名

标题_时间码_备注.mp4 / .webm

时间码固定取入点时间码（如 00391214），备注取同一时刻命中的标记点 / 片段备注，保证文件名里两者对应。没有备注时省略备注段；标题最长 24 字、备注最长 30 字，超出截断，非法字符会换成下划线。

录制诊断日志

录制结束 / 停止时，视频页控制台会输出一行 [MGP-REC] saved {...}（以及 [MGP-REC] range tag ...），排障时可直接看这几个字段：

字段含义
capFps本次录制的目标帧率（跟随源帧率，降级后为降级值）
pacerTicks节拍器出的拍数（≈ 录制秒数 × capFps）
pacerDrops节拍器丢拍数（只在持续积压时丢）
pacerWrites实际提交给编码器的帧数：pacerWrites ÷ 录制秒数 ≈ 文件实际帧率
chunkCount / chunkBytes编码产出的数据块数量 / 字节数（判断编码器是否跟得上）
downgrades本次录制自动降帧的次数
rangeTag色彩范围标签改写结果（如 Range 2→1 ✓ / off(vp9)）
audioVia音频采集方式：audiocontext / capturestream / none（没声音时看这里）
resW / resH / mimeType实际输出分辨率与编码格式

录制期间的其他行为

  • 录制中把页面切到后台：浏览器会停止渲染画面，插件会暂停录制并提示「已暂停录制（页面切到后台）」，回到前台自动继续（提示「已恢复录制」）；
  • 开启设置里的「画中画保持录制」（实验）后，录制开始时自动进入画中画，页面切到后台视频仍在画中画窗口里渲染，录制不会暂停。批量任务期间不会进入画中画；
  • 换集 / 播放器换了 video 元素时录制会跟随新的视频源，无需重录；
  • 录制结束后，本段时长（秒）会写入剪贴板，提示「录制结束 — Ns」。

5日志面板

点击浏览器右上角插件图标打开面板，面板顶部固定标题「日志记录」，下方显示当前视频标题。

三种显示模式

点击右上角「模式」按钮切换：

弹窗→ 侧边栏→ 独立窗口
  • 弹窗：紧凑窗口，用页签切换「标记 | Mark」「片段 | Clip」，只显示当前页签的列表（页签选择会被记住）；
  • 侧边栏：浏览器右侧侧边栏，两组记录上下堆叠，每组标题左侧的箭头可收起 / 展开（收起一组会自动展开另一组）；
  • 独立窗口：430×680 的小窗，可脱离浏览器使用，跟随打开时记忆的来源视频标签页；弹窗 / 侧边栏则跟随当前激活标签页，切换网页后记录自动同步。

插件会记忆上次使用的模式：下次打开浏览器，点击插件图标仍按该模式打开面板（弹窗模式直接弹出；侧边栏 / 独立窗口模式会清空弹窗、以对应方式打开）。切换模式时当前面板会关闭。

面板标题与重命名

面板顶部的网页标题可直接就地改名：点击标题 → 输入新标题 → Enter 保存 / Esc 取消（失焦也会保存），最长 80 字。改名后同步到：历史记录列表、导出表格的标题列、之后截图 / 录制的文件名。只有在面板可用的页面（芒果TV、百度网盘或已授权的站点）才能改名。

记录列表

  • 标记点列表：序号、时间码、五色圆点、备注；片段列表：序号、入点 → 出点、时长（按 0.5 秒取整）、备注。两者都按时间先后排列；
  • 勾选记录用于导出、删除或批量截图 / 录制；未勾选时底部「清除记录」「导出日志」按钮为禁用状态；
  • 点击时间码跳转到视频对应时刻（片段可分别点入点、出点）；
  • 右键单击时间码：复制紧凑时间码，如 00391214（提示「已复制时间码 ( 00391214 )」）；
  • 右键双击时间码：就地编辑该时间码（Enter 保存 / Esc 取消 / 失焦保存）。支持与控制栏右键输入相同的六种格式；片段可分别编辑入点、出点，时长自动重算，改完按时间重新排序；写法不合法会提示「无法识别的时间码：xxx」且不写入；
  • 点击记录行的空白区域：为该条记录添加 / 编辑备注（没有备注时显示「添加备注…」入口）；
  • 标记点颜色：点击行右侧的五个色圆点设置颜色（红 / 橙 / 蓝 / 绿 / 灰），再次点击同一个点取消。颜色会写入导出表格的「颜色」列；
  • 备注：有备注的记录始终显示备注行（与时间码左对齐，无需选中），多行备注完整展示。Shift+Enter 换行（输入框自动增高）、Enter 保存并退出编辑（不影响勾选状态）、Esc 取消、点其他位置也会保存；
  • 底部统计：显示「已选N条记录」，勾选了片段时追加 | 3.5s，统计已选片段的入点到出点总时长（没勾选片段时只显示条数）。

搜索备注

  • 底部「全选」左侧的放大镜按钮：点击展开搜索行（输入框提示「搜索备注」），输入即按备注文本过滤两个列表，不区分大小写；命中的关键词会在备注里高亮显示；
  • 搜索行下方多出一排颜色圆点：点某个颜色就只留下该颜色的标记点，可多选（再点一次取消）；右侧「清除颜色」一键还原；颜色筛选只对标记点生效（片段没有颜色）；
  • 右侧显示「匹配 N 条」/「无匹配」，列表无结果时给出「没有备注含「xxx」的标记点 / 片段」（同时按颜色筛选时会写明两个条件）；
  • 搜索生效时，标记 / 片段右侧「全选」上的数字会变成搜索结果数，此时点它选中的就是这批搜索结果；
  • Esc 清除并收起；右侧 ×：搜索栏为空时点它直接关闭搜索栏，有内容时先清空内容（再点一次才关闭）；输入框里按回车只是退出输入状态，不清除；有筛选时放大镜按钮高亮；
  • 过滤只影响列表显示，不改变记录与勾选状态——可以「搜某品牌 → 全选 → 批量截图 / 录制」。

全选与清除

  • 底部「全选」按钮：搜索 / 颜色筛选生效时只作用于当前可见记录；弹窗模式下只作用于当前页签；
  • 侧边栏里，每组标题右侧的计数标签也可以点击一键全选该组；搜索生效时它显示的是搜索结果数，点它选中的也就是这批搜索结果；
  • 列表中每条记录左侧的序号固定两位（01、02…），超过两位按实际位数显示（100）；
  • 底部垃圾桶按钮「清除记录」：删除所有勾选的记录，会先弹出二次确认「确认删除选中的 N 条记录？此操作不可恢复。」（确认按钮为「删除」，默认焦点停在「取消」）。

批量截图 / 批量录制

在面板中勾选记录（焦点保持在面板内），然后：

  • 勾选标记点后按 S：批量截图，只对标记点生效；
  • 勾选片段后按 R：批量录制，只对片段生效，逐段录制入点到出点；
  • 勾选类型与按键不符时不执行，提示「批量录制只对片段生效，请勾选片段」（截图同理提示标记点）；完全没勾选时按键不拦截；
  • 弹出二次确认弹窗：标题「确认操作」，正文「确认对选中的 N 条标记点依次自动截图？」，按钮「取消 / 开始」；
  • 弹窗里还有一个标题输入框（提示「标题（写入文件名）」）：默认填当前面板标题，可以直接改成这次批量要用的标题 —— 它决定这一批截图 / 录制文件名的「标题」部分（文件名格式 标题_时间码_备注）。改完的标题会同步到面板标题，所以后续单张截图 / 单段录制也用新标题；
  • 键盘操作：← / → 在「取消 / 开始」间切换焦点、Enter 触发当前按钮、Esc 取消；打开时焦点落在标题输入框上（光标在框内时左右键移光标，不会切按钮）；删除类操作的默认焦点停在「取消」，避免误按 Enter；
  • 开始后面板提示「已开始批量截图（N 条）· 按 Esc 取消」，页面右下角逐条显示进度，如 批量录制 2/5 · Esc 取消；
  • 任务进行中按 Esc（焦点在面板或页面内都可以）取消：立即停止当前录制，正在录制的那一段作废不保存（避免留下半截文件），已完成的条目保留，最后提示「批量录制已取消 — 已完成 N 条」；
  • 全部完成后提示「批量截图完成 — 成功 N 条 · 失败 M 条」（失败为 0 时省略后半句）；单条异常、录不出内容（空录制）都只记为该条失败，不会中断整批；被取消的那一条既不算成功也不算失败；
  • 任务逐条可靠执行：每段录制严格停在设定的出点；换集 / 播放器重建导致控制栏重建后任务仍继续；批量期间不进入画中画；任务进行中再次触发会提示「批量任务进行中，请稍候」；
  • 批量任务结束后，页面原有的入点 / 出点 / 标记点状态会自动恢复。

AI 提示词的内容

提示词会要求 AI 只做「时间码 → 项目说明」的提取，主要约定：

  • 逐条提取表中每一个时间码，每条一行，格式为「时间码 + 空格 + 项目说明」；
  • 时间码统一写成规范格式（英文冒号）：带帧号写 时:分:秒:帧（如 00:07:10:21），不带帧号写 时:分:秒（如 00:07:10）；原表的中文冒号、分号、缺前导零、纯数字等写法由 AI 统一转换；
  • 项目说明按「品牌 → 艺人 → 权益 → 时长」拼接，没有的部分省略（如 阿维塔 张泉灵 4s、趣多多 张彬彬 食用）；
  • 不写列名（植入 / 包装 / 空镜…）、分线编号（P1 / P2）；一个单元格里有多个时间码时各占一行；
  • 按时间排序，只输出纯文本，不要表头、标题、合计、解释，也不要 markdown 表格或代码块；
  • 工作表先说清楚：弹窗已经读到文件时，提示词里会列出工作表名，并要求 AI 先说明每张表是什么、问你要导入哪一张再输出；没读到文件（直接点「复制提示词」）时，也会要求 AI 发现有多个工作表就先列出来问你，不要自己替你挑。

粘贴回来的内容兼容纯文本与 JSON 数组；纯文本会自动忽略列表符号、序号、markdown 表格外框。插件本身也兼容中文冒号 / 分号的时间码，表格原文直接粘进来同样能识别。

自动识别规则

  • 时间码识别：6～9 位纯数字串（兼容多打 / 漏打一位、5 个 0 的手写零点），带分隔符的写法中英文冒号与分号都算；
  • 读法自动判定（无需手动选择）：8 位按 时:分:秒:帧，4 位按 分:秒，6 位按首位是否大于 23、再结合视频时长区分 时:分:秒 与 分:秒:帧；
  • 备注只写该条对应的项目：单元格里紧跟时间码的说明与【品牌】标记（如 00295306趣多多空镜 → 备注 趣多多空镜、【阿维塔】013218 → 阿维塔），不带列分类、分线等额外信息；单元格里只有时间码时（露出表这类）退化为品牌 / 秒数（如 阿维塔 4s）；
  • 表名、总时长等标题行整行跳过，不提取时间码；
  • 超出视频时长的行自动丢弃；同一时刻的重复记录自动合并备注；
  • 两种方式都按标记点导入到当前打开的视频，与已有记录按时间码去重（重复的跳过）。

10常见问题

面板提示「当前页面无法访问视频」怎么办？
面板只能在芒果TV视频播放页、百度网盘，或已开启「应用于当前网页」的站点使用。弹窗 / 侧边栏会自动跟随当前激活的标签页，切到视频页即可恢复；独立窗口跟随打开时记忆的来源视频标签页。确认插件已启用，并在设置里给当前网站打开「应用于当前网页」（需要允许浏览器弹出的权限申请）。
按 I / O / M 没有反应？
依次确认：① 焦点不在输入框、备注编辑框或可编辑区域里；② 当前站点适用（芒果TV、百度网盘或已授权的网页）；③ 打点没有被「日志记录」开关挡掉（被关闭时按 I / O / M 会提示「日志记录已关闭」）；④ 「视频控制」没有被关闭——控制栏关闭后页面内的快捷键也不再响应，重新打开即可。另外 J / K / L 变速需要页面里有视频，暂停状态按 J / L 会先开始播放。
录制的视频没有声音？
浏览器对录制声音有权限限制。先看控制台 [MGP-REC] saved {...} 里的 audioVia：none 表示完全没取到音轨。常见原因：视频还没有播放过（浏览器认为你没有播放权限，音频上下文处于挂起状态）；浏览器把标签页静音了；部分加密内容被浏览器禁止采集声音。播放一下视频、解除静音后再录通常就能恢复。
录制帧率偏低 / 画面发顿？
录制编码在设置里选，默认 H.264，全部由 CPU 完成。先看 [MGP-REC] saved {...}：pacerWrites ÷ 录制秒数 ≈ 文件实际帧率。
· pacerDrops 很小而帧率仍低 → 瓶颈在编码器内部丢帧，换更省 CPU 的档位（「低分辨率 H.264」或 VP8）重录；
· pacerDrops 很大 → 编码器长期吃不住，同样建议降档。
编码确实跟不上时插件会自动降帧（60→50→30→25）并弹提示；不会中途改分辨率（改分辨率会让 MP4/H.264 花屏），需要更低分辨率请改用「低分辨率 H.264」重新录制。
录制出来的视频颜色偏深 / 和原片不一样？
插件已经在录制转绘时把画面压到 limited（16-235），并把容器标签一并声明为 limited（WebM 改 Colour/Range；MP4 重封装时改 SPS VUI 与 colr），正常情况下不会偏深。
例外是 VP9 档：它的范围写在码流内部，容器标签改不动，所以 VP9 保持「全范围画面 + 全范围标签」不变；对颜色敏感时请改用 H.264 或 VP8。截图（S 键 PNG）不做压缩，仍是标准 sRGB。
想核对文件的实际色彩信息，可用 ffprobe 看 color_range，正常应为 tv（limited）；控制台 rangeTag 也会记录本次标签改写结果。
导出的 Excel 打不开？
导出的文件是标准 .xlsx，可以用 Excel、WPS、腾讯文档打开。若提示损坏，请更新软件版本后重试。
换集后记录会丢失吗？
不会。每条记录都挂在对应分集的 key 下，面板会自动切换显示当前分集的记录；「历史记录」里可以随时跳回任意分集查看。
批量截图 / 录制按了没反应，或提示「只对标记点 / 片段生效」？
批量截图只对标记点生效、批量录制只对片段生效：勾选标记点后按 S、勾选片段后按 R。如果勾选的类型和按键不符会有提示且不执行；完全没勾选时按键不会被拦截。任务进行中再按会提示「批量任务进行中，请稍候」，按 Esc 可取消。
右键输入时间码提示「无法识别的时间码」？
只支持第 3 节列出的六种写法，且帧号必须小于当前帧率（例如 25fps 时帧号不能大于等于 25）、秒不能大于等于 60。带分隔符时数字之间不能空缺（12:、:12、1::2 都会失败）。
