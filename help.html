芒着拉片｜MG Player+ 使用教程 · v2.0

为芒果TV设计的的视频辅助插件：快捷键打点、变速预览、截图录制，日志面板一键导出片段表。

1快速上手

  1. 在浏览器打开芒果TV视频播放页。
  2. 直接用键盘打点：I 打入点、O 打出点、M 打标记点；用 JKL 变速预览。
  3. 点击浏览器右上角插件图标，打开日志面板 → 勾选需要的记录 → 点击「导出日志」得到 Excel 片段表。

2快捷键速查

快捷键功能
J减速播放（逐级减半，最低 0.25X）
K播放 / 暂停（恢复常速）
L加速播放（逐级翻倍，最高 16X）
空格恢复常速（不暂停）
I打入点：记录当前时刻为片段起点
O打出点：与入点组成一条「片段」记录（自动计算时长）
M打标记点：记录当前时刻，可后续标记颜色
Shift+I O M跳转到最近打下的入点 / 出点 / 标记点
, .逐帧后退 / 前进（按视频帧率 1 帧）
S截图：保存当前画面为 PNG
R开始 / 停止录制画面（含声音）

在输入框或备注编辑中按键不会触发快捷键。若「日志记录」已关闭，打点键会提示「日志记录已关闭」。

3视频控制栏

进入芒果TV视频页后，画面内会出现轻量控制栏：

  • 顶部居中时间码：实时显示当前时间与状态徽章（PLAY / IN / OUT / MARK / REC）。点击可复制当前时间码；打点后自动显示入点以来的计时。右键点击弹出输入框，输入时间码直接跳转，兼容 hh:mm:ss:ff、mm:ss:ff、mm:ss、hhmmssff、mmssff、mmss 六种格式（Enter 跳转 / Esc 关闭）。
  • 鼠标悬停画面时，左右两侧浮现圆形按钮：左侧截图、右侧录制；录制中常驻显示并带红色描边。

4日志面板

点击浏览器右上角插件图标打开面板。面板顶部「日志记录」下方显示当前视频标题（宽度随窗口自适应，拉宽窗口可显示更多文字），点击标题即可就地改名（Enter 保存 / Esc 取消），修改后的标题会同步到「历史记录」列表与导出表格的标题列。弹窗 / 侧边栏模式会跟随当前标签页，切换网页后记录自动同步。

三种显示模式

点击右上角「模式」按钮可切换：

弹窗→ 侧边栏→ 独立窗口
  • 弹窗：紧凑窗口，页签切换「标记 | Mark / 片段 | Clip」（竖线为主题强调色）。
  • 侧边栏：浏览器右侧侧边栏，两组记录上下堆叠，可折叠。
  • 独立窗口：独立小窗，可脱离浏览器使用。

插件会记忆上次使用的模式：下次打开浏览器，点击右上角插件图标仍按该模式打开面板（弹窗直接弹出；侧边栏 / 独立窗口会清空弹窗、以对应方式打开）。

记录操作

  • 勾选记录用于导出或删除；顶部计数标签或底部全选按钮可一键全选。连续多选时高亮合并为一块圆角矩形（仅首尾保留圆角，组内分隔线保留淡化），单条选中保持原样。
  • 点击时间码跳转到视频对应时刻。
  • 点击行空白处复制紧凑时间码（如 00391214）。
  • 标记点颜色：点击记录行右侧的色圆点设为对应颜色，再次点击取消。颜色会写入导出的「颜色」列。
  • 备注：带备注的记录始终显示备注行（与所在行的时间码左对齐，无需选中），多行备注完整展示所有行，编辑与展示状态的换行、行距完全一致；只选中一条记录时，即使无备注也会出现「添加备注…」编辑入口。点击备注即可编辑，Shift+Enter 换行（输入框随内容自动增高），Enter 保存并退出编辑（复选框一并取消勾选），Esc 取消。
  • 底部单行展示 已选 2条记录 | 3.5s：计时器统计已选中的入点到出点记录总时长，未选中任何入出点记录时不显示。

5导出日志

勾选记录后点击「导出日志」，生成 .xlsx 表格（两个工作表：标记 | Mark / 片段 | Clip）：

  • 标记 | Mark：序号 / 时间码 / 颜色 / 备注 / 链接 / 标题
  • 片段 | Clip：序号 / 入点时间码 / 出点时间码 / 时长 / 备注 / 入点链接 / 标题

链接点击可在浏览器中直接打开并自动跳转到对应时刻。

导出文件命名

导出文件按「R/S_标题_备注_时间码_时间」命名：R 表示录制片段（片段记录）、S 表示截图关键帧（标记记录），时间取 mmddhhmmss（如 08011200）。标题 / 备注是否写入文件名由设置中「文件名包含标题 / 文件名包含备注」控制。

R_乘风2026_第3期高光_00115210_08011200.xlsx

6历史记录

点击面板右上角历史按钮，列出所有打过分集（视频）的历史记录，按记录数排序。勾选时可连续选择多项，菜单不会关闭：

  • 每行显示节目标题（与面板上修改过的标题同步）、标记与片段数量，右侧按钮可直接打开该视频。
  • 顶部「全选」与「清除选中」按钮可批量清除某个分集的全部记录（有二次确认）。

8常见问题

面板提示「当前页面无法访问视频」怎么办？
面板只能在芒果TV视频播放页（或已开启「应用于当前网页」的站点）使用。弹窗 / 侧边栏会自动跟随当前激活的标签页，切换到视频页后即可恢复；独立窗口跟随打开时记忆的来源视频标签页。
按 I / O / M 没有反应？
先确认「设置 → 日志记录」已开启；同时确认焦点不在输入框内。另外 J/K/L 变速前需先播放视频。
录制的视频没有声音？
浏览器对录制声音有权限限制。请确认视频已播放过（浏览器认为你有权播放），且浏览器未开启「静音标签页」。部分加密内容可能被浏览器禁止采集声音。
换集后记录会丢失吗？
不会。每条记录都挂在对应分集的 key 下，面板会自动切换显示当前分集的记录；「历史记录」里可以随时跳回任意分集查看。
导出的 Excel 打不开？
导出的文件为标准 .xlsx 格式，请使用 Excel / WPS / 腾讯文档打开。若提示损坏，请更新软件版本后重试。
