芒着拉片/MG Player+ 使用教程 · v4.0

1快速上手

  1. 加载扩展：地址栏打开 chrome://extensions（Edge 用 edge://extensions）→ 开启开发者模式 → 加载已解压的扩展程序，选中插件文件夹。
  2. 打开面板：点工具栏的插件图标。面板有弹窗 / 侧边栏 / 独立窗口三种模式，会记住上次选择。
  3. 打点 → 导出：视频页按 I / O / M 打入点、出点、标记点；回面板勾选记录，点「导出日志」得 Excel。
适用网站芒果TV 与百度网盘打开就能用；其它网站需在设置里打开「应用于当前网页」，并在浏览器弹窗中点「允许」。

3面板功能

记录列表与备注

  • 分「标记点」「片段」两条列表，序号两位补零（01、02…）。
  • 标记点前面的圆点可选五种颜色，再点一次取消颜色。
  • 点记录行的空白处即可加 / 改备注：Enter 保存、Shift+Enter 换行、Esc 取消。
  • 时间码右键单击复制、右键双击就地修改；底部显示「已选 N 条」与时长合计，另有「全选」「清除记录」。

搜索

  • 按备注关键词搜索，命中的词会高亮。
  • 输入框内部靠右的彩色小圆点可按标记颜色筛选标记点（再点一次取消）。
  • 搜索生效时「全选」上的数字变成搜索结果数，点它就是选中这批；搜索框为空时点 × 关闭搜索栏。

批量截图与录制

  • 勾选标记点按 S 批量截图，勾选片段按 R 批量录制；类型不符会提示。
  • 弹窗里可确认并修改标题，标题决定产出文件名。
  • 逐条显示进度，Esc 取消（当前段作废），结束给出成功 / 失败条数。

导出日志

勾选记录后点「导出日志」，生成 .xlsx，含「标记 | Mark」「片段 | Clip」两张工作表。

导入记录

  • 入口：历史记录栏的「导入」按钮，或把 .xlsx 拖进面板。
  • 弹窗三步走，每步点「下一步」：① 选择来源（拖入表格 / 点「点击选择文件」，或直接粘贴时间码清单）→ ② 工作表与方式（选要导入哪张表，选 AI 导入或直接导入）→ ③ 确认清单。
  • AI 导入（推荐）：点「复制提示词」（只针对你选的那张表），把表格和提示词发给 AI，再把结果粘贴回弹窗；直接导入：直接把自动识别结果列出来。
  • 两条路都会先把清单列出来（「将导入 N 条」），确认无误再点「确认导入」；当前视频已有记录时会再确认一次「是否导入到当前视频」。
  • 粘贴时间码清单的话，第一步点「下一步」就直接到确认清单（跳过选表）。
  • 日志记录空表：弹窗左下角有「下载空表」（标记表两栏「时间码 / 备注」，片段表三栏「入点时间码 / 出点时间码 / 备注」），只填时间码就能用，导入到当前视频。
  • 不是本插件导出的表格，弹窗顶部会提示优先用 AI 导入。

时间码输入写法

控制栏右键输入、面板里右键双击时间码、导入的清单，都认这些写法（中英文冒号、分号、有没有分隔符都可以）：00:01:12:18、00：01：12：18、01:12:18、01:12、00011218、011218、0112。

011218 这类 6 位数字既能读作「分:秒:帧」也能读作「时:分:秒」，两种都成立时会弹窗让你选一次，默认「分:秒:帧」；控制栏那个弹窗点一下读法就跳转（↑ ↓ 选、Enter 跳、点弹窗外面取消）。导入时整批按同一种读法换算。

导入进来的时间码一律归一化成 HH:MM:SS:FF 显示；片段还会按入出点自动算出间隔秒数。导出的表格（含下载的空表）所有单元格都是文本格式，011218 这类数字串不会丢前导零。

历史记录

跨网站汇总所有打过点的视频，点击某行在新标签页打开；可多选后批量清除。

批量导出：勾选多个视频后点「导出选中」—— 只选 1 个直接给一份日志表（同名 标题_日志记录_导出时间）；选多个则每个视频一份、一起打包成 zip。表格里的链接带定位，可以直接拖回插件再导入。只有条数、已拿不到明细的视频会跳过，导出提示里会写明。

设置

  • 亮色模式、禁用弹幕、视频控制栏、直播模式、颜色查找表、时间码显示回避、画中画保持录制（实验）、应用于当前网页。
  • 直播模式（在「视频控制」下面）：开启后时间码变成系统时间（HHMMSSFF，固定按 25fps 折算帧号），状态标签由 PLAY 变 LIVE；打点记录、录制与截图的文件名都用这个时间码，同时停用所有按时间码跳转的功能。默认关闭、每次手动开（刷新即回到关闭），直播页默认开启。
  • 菜单里另有三个按钮：网页全屏 / 教程帮助 / 重载插件。

4截图、录制与画面控制

时间码与控制栏

  • 画面顶部时间码：双击复制紧凑时间码，右键可输入时间码跳转；网页全屏用 P / Q / Esc。
  • 「时间码显示回避」开启后悬浮时自动下移，避开顶部遮挡。
  • 画面两侧是截图 / 录制按钮；网页全屏铺满窗口，Esc 退出。
  • 「禁用弹幕」启用期间自动隐藏弹幕；「画中画保持录制」（实验）切到后台不中断录制。

截图与标注

  • S 下载 PNG 并复制到剪贴板；C 只复制、不下载。两者都不会暂停播放；要「图里那一帧 = 嵌入时间码 = 文件名」严格同帧，用 Shift + S 的标注截图（它会停帧）。
  • Shift+S 标注截图：画框 / 加字（字号按截图宽度换算，1080p 64px，与嵌入时间码同字号），Z 撤销、C 复制、Enter 保存、Esc 取消。
  • 时间码按「此刻真正上屏的那一帧」计算（片源首帧 PTS 偏移会自动修正），所以状态栏的时间码、图片里嵌入的时间码、文件名里的时间码始终是同一帧。

颜色查找表（LUT）

  • 没有设置项：按 Q 在 REC.709 → SLog3 → CLog3 → REC.709 之间循环（REC.709 = 原始画面）。
  • 按 Q 循环三档：REC.709（不套 LUT）/ SLog3 / CLog3；切到 LUT 档会自动进网页全屏，不会退出全屏；退出全屏按 Esc 或 P（退出时自动关闭 LUT）。
  • 只想全屏看原片：按 P 进网页全屏，再按 P 或 Esc 退出（不套 LUT）。
  • 覆盖整个网页窗口：画布铺满窗口，画面按原比例摆在其中（画面之外纯黑）——覆盖面是整窗，比例也不变形；截图与录制仍是原始画面。
  • 面板里每条标记的时间码右侧有个小按钮，点一下就把这条时间码改成当前播放的时间码。

录制与编码

  • R 开始 / 停止录制（含声音），录完会把这段时长写进剪贴板。
  • 编码固定 MP4 · H.264 + AAC（无档位可选）：播放器、剪辑软件最通用，声音是 AAC。
  • 分辨率与帧率都跟随源视频，一源帧画一次（不做定时重绘），录制最顺、文件帧数≈源帧数。
  • 录制画面做了色度补偿（编码器会把色度按 limited 缩放却标成 full-range，导致饱和色发灰），黑白灰与原片一致；截图不做这项处理。

文件名规则

  • 截图 / 录制：标题_时间码_备注
  • 日志导出：标题_日志记录_导出时间

5常见问题

面板提示「当前页面无法访问视频」？
面板只在芒果TV、百度网盘或已开启「应用于当前网页」的站点可用。确认当前是视频播放页、插件已启用；其它网站请在设置里开「应用于当前网页」并点弹窗的「允许」。
按 I / O / M 没有反应？
依次检查：焦点是否在输入框里；当前网站是否适用；设置里的「视频控制栏」是否被关掉；O 需要先打过入点。
录制的视频没有声音？
多为浏览器权限问题：视频从没播放过、标签页被静音，或内容受保护不允许采集声音。先播放视频、取消静音，再录一次通常就正常了。
录制画面发灰 / 和原片不一样？
Chromium 的编码器会把色度按 limited 缩放却把文件标成 full-range，导致饱和色掉饱和度。插件已在录制时做了对应的色度补偿，黑白灰与饱和色都应与原片一致（实测最大偏差 3 级）。截图不受影响。
录制帧率偏低？
录制固定 MP4/H.264 + AAC，一源帧画一次、不做定时重绘，主线程开销最低。若仍掉帧，多半是机器编码能力吃紧：关掉其他吃 CPU 的程序，或先用较低清晰度播放再录。控制台 [MGP-REC] 日志里的 draws / encoderSlow 能看出瓶颈在哪。
导出的 Excel 打不开 / 导入的表格识别不出时间码？
导出的是标准 .xlsx，Excel、WPS、腾讯文档都能打开，提示损坏请先更新软件版本。识别不出时间码时改用弹窗里的 AI 导入：把提示词连同表格发给 AI，再粘贴结果。
